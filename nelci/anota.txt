Documentação -> https://expo.dev/


- Abra no Node Js Command Prompt e defina um local para o projeto

- Instalação do EXPO
	(via Node Js Command Promtp) npm install -g expo


1. Criação do Projeto 
	-> (via node js command prompt)  npx create-expo-app nome_projeto

	Exemplo:
	-> (via node js command prompt) npx create-expo-app app-coffee-wp

----------------

2. Acessar o Projeto via Node Js Command Prompt


----------------


3. Pra utilizar menos arquivos
	-> (via node js command prompt) npm run reset-project

----------------


4. Executar o Projeto
	-> (via node js command prompt) npx expo start

Para visualização do navegador pressione W

Para visualização no app EXPO leia o QRCODE

----------------


5. Abra o Projeto no Visual Studio Code

----------------


6. Imagens do Projeto -> As imagens serão salvas dentro do diretório "assets/images"

----------------


7. O projeto criado com o React-Native possui em sua estrutura inicial 2 arquivos dentro do diretório "app"
	- "app/_layout.tsx" 
	- "app/index.tsx" 

As extensões dos arquivos podem ser "tsx" => typescript ou "js" => javascript

*******
"app/_layout.tsx" => Esse arquivo é responsável pelas Rotas da Aplicação e configuração da Barra de Navegação

"app/index.tsx" => Esse arquivo é responsável pela renderização inicial da aplicação

----------------

8. Navegação na aplicação

Para a navegação é utilizado o componente "LINK" do "expo-router" e é necessário criar a rota no arquivo "_layout.js"

----------------

9. Rotas e Configurações de estilo da barra de navegação no Projeto "app-coffee-wp"

********
"app/_layout.tsx"


import { Stack } from "expo-router";

export default function RootLayout() {
  return (
    <Stack
      screenOptions={{
        headerStyle: {
          backgroundColor: "#010101",
        },
        headerTintColor: "#fff",
        headerTitleStyle: {
          fontWeight: "bold",
        },
        headerTitleAlign: "center", // Centraliza o título na barra de navegação
      }}
    >
      {/* <Stack.Screen name="index" options={{ headerShown: false }} /> */}
      <Stack.Screen name="index" options={{ title: "Coffee WP" }} />
    </Stack>
  );
}

GIT E GITHUB

EXEMPLOS DE VINCULAÇÃO DE PROJETO

1. Instale o Git na máquina, Dê um botão direito na pasta do projeto e selecione "Open Git Bash Here"
2. Configure o e-mail 
	git config –global user.name “Seu Nome”
	git config –global user.email “Seu E-mail”

3. Inicie o Git
	git init

4. Verifique o Status
	git status

5. Crie o Repositório no GitHub - GitHub.com - New Repositório
6. Vincule o Repositório Local ao Repositório no GitHub

	git remote add origin https://github.com/professornelcimariano/projeto_react_cinema.git

7. Exibe o Repositório vinculado
	git remote -v

8. Insira os arquivos na Área Intermediária
	git add .

9. Verifique o Status
	git status

10. Commite dos arquivos no Repositório Remoto
	git commit -m "1 Commit do Projeto - Preparação do projeto, Componentes iniciais e Page Home"

11. Enviar os arquivos para o Repositório Remoto - O primeiro push de um repositório deve conter o nome do repositório remoto e o branch.
	git push -u origin master

12. Visualize os arquivos no Repositório Remoto - Branch Master

13. Verifique o Status
	git status
